# Review-cycle gotchas

Anomalous mutation-test pass (even an "unrelated" mutation) is the bug report — fix the assertion immediately, don't shelve it for a narrower mutation that happens to fail. Fetch opaque GitHub IDs (comment/thread) immediately before use, never from memory; grep a file for an identifier before binding a new top-level `const`/`function` with that name. Dispatch a plan's independent nodes as parallel `isolation: "worktree"` agents from the start of the wave; `git stash` is blocked here — use `git diff -- <files> > patch; git checkout -- <files>; ...; git apply patch` instead.
